# 운영 도구 소스

이 디렉터리는 운영 계정·서버·인증 정보를 포함하지 않은 도구 소스입니다. 실제 운영용 서비스 파일, 배포 절차와 백업 데이터는 공개 사본에 포함하지 않았습니다.

`retention.py`는 지정한 로컬 경로의 백업·보관 처리를 수행합니다. 사본의 기본 앱 경로는 `/srv/opentalk` 예시입니다. 실행 전에 본인의 경로·소유권·백업 범위와 적용 동작을 검토해야 합니다. 준비 과정의 테스트는 임시 디렉터리만 사용했습니다.

`web-upgrade/upgrade.py`의 릴리스 프로필은 이전 스키마 1·4·5·6의 배포 경계를 다루는 코드입니다. 현재 웹 저장소는 스키마 8이므로 이 도구를 현재 소스의 배포 절차로 그대로 사용할 수 없습니다. 관련 테스트는 합성 릴리스의 보존·실패·롤백 동작과 현재 저장소의 임시 DB 호환성을 확인합니다. 현재 운영 배포를 지원하려면 별도 프로필·파일 범위·서비스 설정 검증이 필요합니다.

Linux 소유권·systemd·암호화 키와 실제 계정 연동은 Windows에서 수행한 사본 검증에 포함되지 않습니다.
