# 선택형 카카오 수신기

`start.mjs`는 `src/kakao/welcome-*.js`의 로그인·입장 감지·환영 메시지 구성 요소를 연결하는 진입점입니다. 의존성은 이 폴더의 `package.json`과 `package-lock.json`에 고정한 `node-kakao`입니다. Discord 봇의 기본 실행에는 이 패키지가 필요하지 않습니다.

운영 계정, 기기 식별자, 암호화 키, 방 선택, 수신 상태 파일과 실제 계정의 로그인 정보는 공개 사본에 포함하지 않습니다. 스크립트를 실제로 실행하면 계정 인증과 로컬 상태 저장 과정이 시작될 수 있습니다. 본인의 환경에서 제공자의 이용 조건과 필요한 설정을 확인한 뒤 사용하세요.

사본 준비 과정에서는 수신기를 기동하거나 로그인하지 않았고 새 패키지도 설치하지 않았습니다. 어댑터·입장 이벤트·확인·메시지 처리 테스트는 합성 입력과 주입한 가짜 API를 사용합니다. SDK 자체를 사용하는 진입점의 실제 로그인과 서비스 연동은 별도 검증이 필요합니다.
