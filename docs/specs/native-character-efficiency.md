# 팔찌·아크그리드 젬 자체 효율 모형

기준일 2026-09-16, 모형 버전 `2026-09-16.2`.

공식 Open API 자료만으로 팔찌 8배율과 젬의 전체 점수 비교를 로컬에서 계산한다. 실행 중 외부 사이트의 HTML/JavaScript/계산 결과를 받거나 실행하지 않는다. 결과는 게임의 실제 DPS가 아니라 명시한 계수와 조건으로 계산하는 추정 모형이다. 기존 화면의 배지와 동일한 비교 기준을 재구성하며 숫자 맞추기용 추가 보정은 사용하지 않는다.

## 입력·출력

`analyzeNativeEfficiency(raw,{crit,now})`의 raw는 프로필·장비·각인·스킬·아크패시브·아크그리드와 아바타를 포함한 공식 결합 자료다. now는 epoch 밀리초 또는 그 값을 반환하는 함수다. 최상위 `source:official-api`는 입력 출처이며 모형 상수가 공식 게임 계수라는 뜻이 아니다. `calculatedAt`은 epoch 밀리초다. 입력을 변경하지 않으며 잘못된 입력은 unavailable로 격리한다.

팔찌/젬 공통 필드는 status, efficiency(%), assumptions, formulas, omitted다. 팔찌는 factors와 diagnostics로 8배율 및 공격력·C/H/Q·속도·치특신 중간값을 제공한다. 젬은 optionEfficiency, pointEfficiency, effectEfficiencies와 현재/옵션제외/기준 점수의 diagnostics를 제공한다. 개별 효과의 effect는 공식 백분율 숫자, description은 평문 툴팁이다.

| 상태 | 의미 |
|---|---|
| ok | 이 모형에 필요한 입력을 모두 해석함. 실제 DPS 보장이 아니므로 추정 표시 유지 |
| absent | 명시적으로 해당 장비가 없음 |
| unavailable | 자료를 해석할 수 없거나 계산할 수 없음 |
| unsupported | 해당 역할의 모형 지원 범위 밖 |

누락/미지원 null과 계산상 기여가 없는 0을 구별한다. 팔찌 티어·옵션·기준 자료 중 하나라도 해석할 수 없으면 unavailable과 구체 사유를 제공한다. 일부 낮은 값으로 대신하는 부분 모형은 제공하지 않는다. 서포터 역할 판정과 버프 모형은 별도 모듈의 계약을 따른다.

## 팔찌 8배율

`src/bracelet-model.js`는 raw→기준 입력 변환과 `calculateBraceletFactors(input)` 순수 kernel을 제공한다. `src/bracelet-attack-context.js`가 공격력 분자/분모를 재구성한다. 모형에 필요한 숫자 표는 `src/data/bracelet-model.json`에 별도로 고정했다. 실행 가능한 원문 코드를 데이터에 포함하지 않는다.

전체 배율 M은 아래 8배율의 곱이다. 최종 배지는 `floor((M×1.021−1)×10000)/100`이다. 1.021은 추정 배지의 보정 상수이며 게임 피해 효과가 아니다. 단계별 표시값을 재계산에 사용하지 않는다.

1. **공격력**: 팔찌 주 능력치/무공을 제거한 최종 공격력을 분모, 해당 효과만 복원한 공격력을 분자로 사용한다. raw 프로필에 보이는 버프 시점의 총 공격력을 그대로 쓰지 않는다. 장비 주 능력치, 펫, 아바타, 무공·깨달음 카르마, 공증, 스톤·보석·완갑·코어를 재구성하며 각 단계의 floor를 유지한다. 공격력 전용 모듈의 without/with가 이 분모/분자다.
2. **추가 피해**: `(100+B+b)/(100+B)`. B는 무기 품질·목걸이·젬·안정적인 공격 코어의 팔찌 제외 추피, b는 팔찌 추피다. 품질식은 `10+0.002×품질²`이며 참조 모형의 품질0 처리도 명시 범위에 따른다.
3. **치특신**: 팔찌 제외 합 S와 팔찌 합 d에 대해 `(1.3+0.00041×(S+d))/(1.3+0.00041×S)`. 제압·인내·숙련은 포함하지 않는다.
4. **치적·치피**: 아래 민감도 식을 사용한다. 일반 기대 피해비와 동일한 식으로 대체하지 않는다.
5. **공격 속도**: 팔찌 제외 공속 A와 팔찌 공속 d에 대해 `1+max(0,min(A+d,140)−A)×0.017/6`. A는 모형의 증가량 필드로서 임의로100을 추가하지 않는다.
6. **최종 피해**: 독립적인 직접 피해 배율들을 곱하며 쿨 증가 옵션은 `finalDmg/(1+0.7×cdr)`로 보정한다. 다른 치적·치피·추피 항목에 들어간 효과는 이 항에서 제외한다. 악마 피해는 기본 끔이다.
7. **무력화 대상**: `1+0.25×(무력화 피해 배율의 곱−1)`. 25%는 모형의 피해 비중 가정이다.
8. **방향성·나머지**: 기습/결투/타격 각인으로 back/head/normal을 정하고, 적용 가능한 방향성 배율만 곱한다. 이미 다른 배율에 반영한 옵션은 제외한다. 미확인 옵션은 임의 수치로 만들지 않고 missing에 남긴다.

### 치적 C·치피 H·치명타 주피 Q

C는 팔찌를 제외한 기준 치적이다. `floor(치명/.2794)/100`에 반지·코어·진화·깨달음·직업·각인·선택한 스킬 트라이포드를 더한 뒤 소수 둘째 자리 반올림한다. 기본 시너지/서포터 팔찌는0이며 백어택10을 자동으로 더하지 않는다. 현재 화면의 analyzeCrit.total과 정의가 달라 그대로 대입하지 않는다.

H는200에 각인·깨달음·직업·반지·코어·선택한 트라이포드 모형 값을 합산한다. Q는 회심 채용 시1.12와 코어별 치명타 주피 배율의 곱이다. 직업의 버프 상태와 질풍노도의 이동속도 연동, 비기의 특화 연동 등은 버전 고정 표/식으로 재현한다.

팔찌 직접 치적 dc, 치피 dh, 배지용 치명 주피 곱 q, 공증 보정 곱 a를 분리한다. 일부 실제 치명 주피1.5% 옵션의 배지용 값은1.01이며 실제 게임1.015와 구별한다. 같은 옵션의 반복 보조 효과는 각각 보존한다.

치적 상한 K는 뭉툭한 가시 없음100/Lv.1 116/Lv.2 이상120이다. C를 K로 제한한다. `E(C,H,Q)=(1−min(C,100)/100+min(C,100)/100×H/100×Q)×뭉툭한가시진피배율`.

뭉툭한 가시 진피량은 Lv.1에서 `min(7.5+max(0,min(C,120)−80)×1.25,52.5)`, Lv.2 이상에서 `min(15+max(0,min(C,120)−80)×1.5,75)`이고 진피배율은 `1+진피량/100`이다.

`x=E(min(C+1,K),H,Q)/E(C,H,Q)−1`, `y=E(C,H+1,Q)/E(C,H,Q)−1`, `d=clamp((x−y)/(|x|+|y|),−1,1)`이며 분모0이면 d=0이다.

`Rcrit=(1+0.007×(1+0.024d)×max(0,min(C+dc,K)−C))×(1+0.0035×(1−0.024d)×dh)×q×a`.

### 옵션 단위와 입력 경계

공식 팔찌 아이콘 한 묶음 전체를 하나의 옵션으로 매칭한다. 미확인 조건/후속 문장이 붙은 옵션에서 익숙한 문장만 추출하지 않는다. 알 수 없는 옵션과 알려진 비딜 옵션을 구별한다. 쉼표는 정상 천 단위 구분만 허용한다. 부정확한 숫자·중복 슬롯·알 수 없는 등급·모형에 없는 코어·필수 배열 누락은 missing에 명시한다.

직업/코어 숫자 표는 게임 툴팁과 같은 것이 아니라 버전 고정 추정 모형의 수치다. 새 직업·코어·등급은 표를 검토하기 전까지 완전 계산으로 표시하지 않는다. 원문 프로그램의 누락 시 암묵적인0이나1 처리는 그대로 정상값으로 숨기지 않는다.

## 젬 전체 점수 비교

`src/native-gem-efficiency.js`는 현재 U, 젬 합산 옵션만 제거한 O, 옵션을 제거하고 코어를 기준 포인트로 낮춘 B의 점수를 각각 계산한다. 기준 포인트는 각 활성 젬의 질서/혼돈 포인트를 합산해 현재 코어에서 뺀 뒤 최소17로 유지한다. 현재17P 이하 코어는 그대로 둔다. 포인트는 줄 전체의 단위 없는0..5 정수만 허용하며 과거10배 단위10/20/30/40/50은10으로 나눈다. 비활성 젬은 포인트에 더하지 않는다. 명시적으로 팔찌를 착용하지 않았으면 팔찌 배율1로 젬 비교를 계속한다.

비교에서 바뀌는 항만 곱한다.

`점수 = 팔찌제외 normalAttack × (1+팔찌제외추피/100) × 코어직접피해 × 직업공통코어 × (1+젬보스피해/100) × 팔찌8배율`.

각인 최종공격력 대신 공격력 재구성의 diagnostics.without.normalAttack을 사용한다. 다른 장비·각인·일반 보석·진화/깨달음/도약·스탯 등은 세 자료에서 같아서 상쇄된다. 선택 스킬 비중을 바꾸는381개 모형 조건은 모두 코어14P 기준이므로17P 비교에서는 빌드가 바뀌지 않는 것을 정적 자료로 확인했다.

직업공통코어는 해당 계열의 주력/별 코어 목록과 등급·포인트 표를 사용한다. 해·달 둘 중 하나만 있으면14P 이상 효과의 평가 포인트를10으로 제한한다. 클래스 표의 공백 차이는 정규화한다. 알려진 코어의17P 이하 중간 포인트에 정확히 대응하는 치적·치피·주피 표 행이 없으면 원래 모형과 같은 중립값을 사용한다. 이는 직전 단계 툴팁을 누적한 실제 게임 효과 해석과 구별되는 비교 모형의 규칙이다. 새로운 코어 이름이나17P 초과 미확인 표 행은 누락으로 처리한다.

- 전체: `floor((U/B−1)×10000)/100`
- 옵션: `floor((U/O−1)×10000)/100`
- 포인트: `floor((O/B−1)×10000)/100`
- 합산 효과 종류별 기여: 해당 효과 하나만 제외한 점수 X와 비교해 `floor((U/X−1)×10000)/100`

옵션과 포인트 효율을 더해 전체를 만들지 않는다. effectEfficiencies는 개별 젬 한 칸의 교체 효과가 아니다. 공식 합산 Effects를 사용하므로 개별 젬 옵션을 다시 더하지 않는다. 각 반사실도 같은 순수 mapper와 공격력/팔찌 kernel로 재평가한다.

## 서포터 버프 비교

`src/native-support-efficiency.js`는 직업과 실제 채용한 깨달음 노드를 함께 확인한다. 바드의 절실한 구원, 도화가의 만개, 홀리나이트의 축복의 오라, 발키리의 해방자가 해당한다. 직업 이름만으로 서포터로 분류하지 않는다.

기준 딜러 공격력 170,000, 지원 특성의 신속:특화 75:25 환산(원래 특화는 최대 1,200), 공증·낙인·아이덴티티·초각성 버프 가동률을 사용하는 모형이다. 실제 파티의 플레이를 재현한 DPS 계산은 아니다. 지원 공격력은 장비·악세·팔찌 주 능력치와 아바타, 무기·완갑·카르마를 재구성한다. 딜러의 펫 1%와 일반 공격력 증가 각인·아크그리드 공격력 효과는 넣지 않는다. 일반 보석의 기본 공격력 보너스는 포함한다.

공증 두 스킬의 지속시간·재사용 대기시간과 선택된 빠른 준비, 신속, 마나의 흐름·각성·선각자, 스킬 보석을 반영한다. 상시 버프에 아이덴티티와 초각성의 켜짐/꺼짐 네 조합을 합친 종합 버프 배율 T를 구한다. 모형의 장비·스킬·버프 조건은 팔찌 포함/제외 비교에서 동일하게 유지한다.

- 팔찌: `floor(((T포함/T제외)^4.24−1)×10000)/100/1.4`. 내림 후 1.4로 나누며, 화면에서는 소수 둘째 자리로 표시한다.
- 젬: 현재 U, 합산 옵션만 제거한 O, 옵션 제거와 17P 기준 적용 B를 종합 버프 배율로 각각 계산한다. 전체·옵션·포인트는 딜러와 같은 U/B·U/O·O/B 비율을 사용한다. 질서 코어의 최종 점수 보정은 버프 배율에 들어가지 않는다.
- 공격력·추가 피해·보스 피해처럼 지원 버프에 기여하지 않는 젬 옵션은 0%를 보존한다. 자료 누락을 0%로 바꾸지 않는다.
- 코어 기준표는 10·14·17·18·19·20P다. 중간 포인트의 비활성 값과 흐르는 마나의 이전 구간 쿨다운 적용을 가정에 명시한다. 알려진 임계점의 표 행이 없거나 옵션·등급·슬롯을 확인하지 못하면 계산을 거부한다.

공식 `ArkGrid:null`과 명시적인 빈 보석 응답은 미장착이다. 젬 포인트 해석 실패는 젬 계산에서 격리하므로, 포인트 제거를 필요로 하지 않는 유효한 팔찌 계산을 함께 버리지 않는다.

## 검증과 제한

단위검사: `node --test tests/*.test.mjs`. 공격력 재구성·팔찌·딜러 젬·서포터·웹 진입점 분기를 함께 검사한다.

공식 full raw 5개와 독립적으로 읽은 현재 화면의 팔찌 결과15.62/14.36/13.92/14.04/13.05, 젬 결과9.41/12.40/7.05/5.93/10.37를 대조한다. 수치만 맞추지 않고 각8배율, C/H/Q, 공격력 분해, 세 젬점수와 효과별 기여를 함께 보관한다. 개인 캐릭터 자료는 비공개 검증 폴더에만 저장한다.

서포터 공식 응답 두 개는 팔찌16.18/17.53, 젬3.03/2.06, 옵션2.82/1.86, 포인트0.20/0.19의 실제 화면과 대조했다. 이는 확인한 장착 정보의 일치이며 모든 직업·향후 패치의 일치를 보증하지 않는다.
