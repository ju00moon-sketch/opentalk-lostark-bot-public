1. 계정과 길드 가입: 수집 항목과 목적

이용자가 요청한 로그인·길드 관리·챗봇 기능에 필요한 정보는 서비스 이용계약의 체결·이행을 위해 처리합니다. 별도 동의를 받아 처리하는 선택 기능은 해당 화면에서 목적과 항목을 안내합니다. 이 방침은 처리 사실을 알리는 문서이며, 로그인 안내가 법령상 별도로 받아야 하는 동의를 대신하지 않습니다.

디스코드 또는 카카오로 처음 로그인하면 해당 서비스의 고유 계정 ID와 표시 이름(닉네임), 계정 생성·로그인 시각을 저장합니다. 이 정보는 같은 회원을 확인하고 계정 화면과 로그인 기능을 제공하는 데 사용합니다. 직접 닉네임을 설정한 카카오 회원은 설정한 이름을 유지하며, 그 외에는 다시 로그인할 때 표시 이름을 갱신합니다.

디스코드와 카카오 모두 인증할 캐릭터명을 입력하면 로스트아크 공식 API에서 캐릭터명·서버·직업·아이템 레벨·길드명을 확인합니다. 캐릭터 소유 인증 상태, 인증 방법·시각과 확인한 캐릭터 요약을 회원 탈퇴 전까지 저장합니다. 기존 카카오 회원이 직접 설정한 닉네임과 대표 캐릭터 정보는 유지합니다. 캐릭터 정보가 조회되는 것만으로 소유 인증이나 가입 승인이 완료되지는 않습니다.

이메일·프로필 사진·친구 목록은 저장하지 않습니다. 외부 서비스의 접근 토큰은 로그인 정보를 확인할 때만 사용하며 저장하지 않습니다. 두 서비스의 계정을 닉네임이나 이메일로 합치지 않습니다.

길드 가입을 신청하면 대표 캐릭터명, 신청·심사 시각, 신청·승인 상태와 관리 권한을 함께 저장합니다. 길드 관리자는 가입 심사와 일정 열람 권한 관리를 위해 로그인 서비스, 표시 이름, 대표 캐릭터명과 신청 상태를 확인합니다. 최고관리자는 승인 회원에게 관리자 권한을 부여하거나 회수할 수 있습니다.

승인 후 내 계정에서 대표 캐릭터를 선택하면 캐릭터명·서버·직업·아이템 레벨과 선택·확인 시각을 저장합니다. 인증된 계정의 보유 캐릭터인지 공식 API로 확인하며, 기존 인증과 가입 승인 기록은 유지합니다. 선택 정보는 상단 프로필과 빠른 검색에 사용하고 회원 탈퇴 시 삭제합니다. 보유 캐릭터 목록과 얼굴 이미지는 회원 데이터베이스에 저장하지 않습니다.

STOVE로 인증할 때는 제출한 프로필 주소에서 계정 식별자를 확인하고, 공개 소개글의 일회용 인증 코드와 해당 계정의 로스트아크 보유 캐릭터를 대조합니다. 소유 인증에 성공한 STOVE 계정 식별자는 인증 방법·시각과 함께 내부에 보관하며, 관리 화면에는 인증 상태·방법·캐릭터 정보만 표시합니다. 제출한 프로필 URL, 소개글 전문과 전체 보유 캐릭터 목록은 저장하지 않습니다. STOVE 비밀번호나 로그인 쿠키를 요구하지 않습니다.

디스코드 캐릭터 인증을 선택하면 추가 동의를 받아 KOR Lost ARK 서버의 지정 역할과 서버 별명을 조회합니다. 해당 디스코드 계정에서 인증된 대표 캐릭터명이 입력한 이름과 같은지 확인하고, 공식 API에서 캐릭터와 루페온 서버 정보를 대조합니다. 접근 토큰과 전체 역할 목록은 저장하지 않습니다. 인증이 완료되어도 홈페이지 가입은 자동 승인되지 않으며, 별도로 신청한 뒤 운영진의 심사를 거칩니다. 디스코드 인증을 이용할 수 없으면 STOVE 프로필 인증을 진행할 수 있습니다.

일회용 코드는 현재 회원·로그인 세션·선택한 캐릭터에 연결하며 발급·만료 시각과 시도 횟수를 임시 보관합니다. 코드는 30분 후 만료되고, 재발급·인증 완료·탈퇴 시 교체하거나 삭제합니다. 디스코드 추가 인증을 연결하는 임시 정보는 최대 5분 동안 사용하고 사용·만료 후 삭제합니다. 만료된 정보는 정기 정리합니다. 기존 가입 신청과 승인·거절·열람 철회 상태는 보존하며, 운영진의 승인이 철회되면 다시 심사를 받아야 합니다.

2. 보관 기간과 삭제

회원 정보는 회원 탈퇴 전까지 보관합니다. 내 계정에서 회원 탈퇴를 선택하면 이 홈페이지의 회원 정보, 길드 가입 신청·승인 상태·관리자 권한과 모든 로그인 세션을 삭제합니다. 본인 확인을 위해 최근 5분 이내 로그인이 필요합니다. 다시 가입하면 길드 승인을 새로 받아야 합니다.

카카오로 가입한 회원이 탈퇴하면 카카오와 포근해용의 연결도 해제합니다. 카카오에서 직접 연결을 해제하면 전달받은 연결 해제 알림에 따라 홈페이지 회원 정보를 삭제합니다. 연결 해제 처리 도중 오류가 발생하면 처리를 마치는 데 필요한 계정 ID와 요청 정보를 일시 보관하고, 재시도 완료 후 삭제합니다. 처리가 끝날 때까지 해당 홈페이지 계정의 로그인과 이용은 제한됩니다.

카카오 연결 해제로 홈페이지 회원 정보를 삭제할 때도 길드 가입 신청·승인 상태·관리자 권한을 함께 삭제합니다.

회원 탈퇴나 카카오 연결 해제로 회원 정보를 삭제하면 소유 인증 정보·일회용 코드·추가 인증 정보와 수동 심사 표시도 함께 삭제합니다.

디스코드·카카오의 원래 계정, 디스코드 서버 가입 상태와 봇의 출석·캐릭터 등록 기록은 홈페이지 탈퇴로 변경되지 않습니다. 홈페이지와 봇의 기존 기록은 별도로 관리합니다.

챗봇 출석·등록·이용 제한 기록은 해당 기능의 제공과 기존 기록 확인을 위해 유지하며, 등록 해제·삭제 요청·운영 종료 시 해당 범위의 기록을 정리합니다. 월간 출석 집계나 하루 이용 한도의 초기화는 사용자 기록 전체를 삭제하는 절차가 아닙니다. 메뉴 추천 내역은 같은 날의 중복 방지에 사용하고, 날짜가 바뀐 뒤 다음 추천 처리 때 새 내역으로 교체합니다.

장애 분석에 사용하는 일반 운영 로그와 복구용 백업은 30일을 기준으로 보관하며, 매일 보관 기간이 지난 기록과 사본을 정리합니다. 등록 해제나 홈페이지 탈퇴만으로 백업 사본까지 즉시 지워지지는 않으며, 삭제 요청 시 관련 사본의 처리도 함께 확인합니다. 이 기간은 서비스 이용 중 유지하는 계정·출석·등록·일정표의 원본 기록을 30일마다 지운다는 뜻이 아닙니다.

관리자의 개인정보 처리시스템 접속 기록 등 법령상 별도 보존 의무가 있는 기록은 해당 보관 기준을 적용하며 일반 운영 로그의 30일 정리 대상에서 제외합니다.

개인정보는 목적을 달성하거나 삭제 요청의 처리가 끝나 더 이상 필요하지 않으면 해당 저장소에서 삭제합니다. 법령상 보존 의무가 있는 경우에는 보존하는 항목·근거·기간을 안내하고 해당 목적에 한해 보관합니다. 전자 기록과 접근이 제한된 복구 사본을 함께 확인하며, 홈페이지 탈퇴만으로 다른 플랫폼이 보관하는 자료를 삭제할 수는 없습니다.

3. 길드 일정표

길드 승인을 받은 회원과 운영자는 홈페이지의 길드 일정표를 이용할 수 있습니다. 일정표에 입력한 캐릭터명·직업·일정과 작성 계정의 연결 정보를 서비스 서버에 저장하며, 승인된 길드원끼리 공유합니다. 길드원은 본인이 작성한 항목을 수정할 수 있고, 운영진은 전체 일정과 숨긴 시트를 관리합니다. 가입 승인이 철회되면 일정표를 조회하거나 수정할 수 없습니다. 홈페이지 일정표를 이용할 때 Google 스프레드시트에 접속하거나 내용을 전송하지 않습니다.

일정 항목은 본인이나 운영진이 삭제·정리할 때까지 보관합니다. 홈페이지 계정을 탈퇴하면 작성 계정과의 연결은 해제되지만 칸에 적힌 내용은 남습니다. 내용까지 삭제하려면 탈퇴 전에 본인이 지우거나 운영진에게 요청해 주세요.

4. 챗봇과 인공지능 기능

명령 처리·출석·캐릭터 등록·알림

명령 처리에는 채팅 플랫폼의 사용자 식별값 또는 표시 이름, 서버·채널·채팅방 정보, 명령 내용과 처리 시각을 사용합니다. 카카오톡 봇은 알림에서 확인할 수 있는 방·발신자 정보와 설정된 형식의 명령을 서버로 전달합니다. 이 정보는 카카오 로그인으로 받은 홈페이지 계정 ID와 별개입니다.

출석 기능은 방과 사용자 구분 정보, 표시 이름, 출석 날짜·횟수·포인트를 저장합니다. 연결된 방은 Android 알림의 대화 식별값과 기존 출석 기록의 연결을 저장하여 방 이름 변경 후에도 기록을 유지합니다. 캐릭터 등록은 사용자 구분 정보와 등록 캐릭터명을 저장하며, 등록 캐릭터는 랭킹 집계에도 사용될 수 있습니다. 알림에는 종류와 대상 서버·채널 등 전달 설정을 저장합니다. 한마디는 사용자별 최근 이용 날짜, 제공한 문장과 생성 답변·준비된 목록 중 어느 방식으로 제공했는지 저장하여 이용 제한과 중복 방지에 사용합니다.

명령·출석 현황·봇 답변은 요청한 채팅방에 표시될 수 있습니다. 긴 결과를 링크로 제공하면 링크를 아는 사람도 내용을 볼 수 있습니다. 임시 결과의 조회 유효기간이 끝나면 조회가 제한되며, 대화 플랫폼의 메시지나 이용자가 복사한 내용까지 삭제되지는 않습니다.

장애 확인을 위한 명령 처리 로그에는 요청 내용, 일부 사용자 구분 정보, 처리 시간과 오류 정보가 남을 수 있습니다. 보관과 삭제 범위는 2절에서 안내합니다.

한마디·메뉴 추천·둘 중 하나 고르기·질문 답변

답변 생성을 위해 OpenAI API를 이용합니다. 한마디에는 생성 조건을, 메뉴 추천에는 식사 구분·시각·서울 날씨 등 추천 조건과 같은 날 최근 추천 메뉴·코멘트를 전달합니다. 메뉴 추천을 위해 개인의 현재 위치를 수집하지 않습니다.

둘 중 하나 고르기에는 입력한 비교 문장과 선택 결과를 전달하여 코멘트를 요청합니다. 문장에 개인정보를 넣으면 그 내용도 함께 전달될 수 있습니다. 홈페이지 계정 ID나 출석 기록을 인공지능 입력에 추가하지는 않습니다. 답변은 이용을 돕기 위한 정보이며 이용자의 권리·자격을 심사하는 자동화된 결정에 사용하지 않습니다.

질문 답변(/챗)에는 이용자가 입력한 현재 질문을 OpenAI API로 전달합니다. 이전 대화나 다른 사람의 질문, 사용자·채팅방 식별값은 답변 생성 입력에 추가하지 않습니다. 질문을 다음 대화에 이어 쓰는 이력 파일은 만들지 않으며, 중복 요청과 지연된 응답을 처리하기 위해 서버 메모리에서 잠시 보관할 수 있습니다. 카카오톡 명령 처리 로그에는 질문 본문을 남기지 않습니다. 질문과 답변은 이용한 채팅방의 메시지로 남을 수 있습니다.

5. 로그인 쿠키·브라우저 저장과 접속 제한

로그인 유지 쿠키는 7일 뒤 만료되며, 로그인 진행을 확인하는 쿠키는 5분 뒤 만료됩니다. 쿠키의 비밀값은 서버에 해시로 저장하고 만료된 인증 정보는 주기적으로 정리합니다. 광고나 분석용 쿠키는 사용하지 않습니다.

과도한 로그인 요청을 제한하기 위해 접속 IP별 요청 횟수를 서버 메모리에 10분 단위로 임시 보관하고 만료된 항목은 매분 정리합니다. 이 정보는 회원 프로필에 저장하지 않습니다. 인증 요청 주소·로그인 코드·쿠키·비밀키를 접속 로그에 남기지 않습니다.

라이트·다크·시스템 중 선택한 화면 모드는 이 브라우저의 로컬 저장소에 보관하며 서버로 전송하지 않습니다. 사이트 데이터를 지우면 저장한 선택도 없어집니다. 시스템 모드는 기기의 화면 설정을 따릅니다. 브라우저에서 쿠키와 사이트 데이터 저장을 차단하면 로그인 유지나 화면 모드 기억이 제한될 수 있습니다.

최근 조회한 캐릭터와 즐겨찾기, 시장의 관심 아이템도 이 브라우저에 저장합니다. 승인된 상태에서만 목록을 읽어 화면에 표시합니다. 목록 전체를 계정에 연결하거나 서버로 전송하지 않으며, 목록에서 항목을 선택해 조회하면 해당 캐릭터명 또는 아이템 검색어만 조회 요청에 사용합니다. 사이트 데이터를 지우면 이 목록도 삭제됩니다.

승인 회원의 게임 정보 조회와 인증 과정의 과도한 요청은 접속 IP별 단기 횟수로 제한합니다. 캐릭터·아이템·소식 조회 결과는 최대 5분 동안 서버 메모리에 임시 보관해 같은 요청을 줄이며, 회원 프로필이나 영구 조회 이력으로 저장하지 않습니다.

6. 외부 로그인·자료 제공처

로그인할 때 선택한 서비스의 인증 화면으로 이동합니다. 해당 서비스의 계정 처리에는 각 서비스의 개인정보 처리방침이 적용됩니다. 홈페이지의 로그인 정보는 Oracle Cloud 서버에서 보관하며 마케팅이나 광고에 이용하지 않습니다.

디스코드 개인정보 처리방침 · 카카오 개인정보 처리방침

게임 정보 조회에는 로스트아크 공식 API, 로펙 등 해당 기능의 공개 자료 제공처에 캐릭터명이나 품목·검색 조건을 전달합니다. 메뉴 날씨는 서울 지역의 예보 조건을 사용합니다. 외부 링크를 직접 열면 해당 사이트가 접속 정보를 처리할 수 있습니다.

개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 요청한 기능의 수행과 위에 안내한 처리위탁·보관 외의 제3자 제공이 필요하면 법령에 따른 근거나 별도 동의를 확인합니다.

7. 국외 처리·보관

서비스 서버: Oracle Cloud

홈페이지 회원·길드·일정표 정보와 챗봇 운영 기록은 Oracle Cloud 일본 오사카 리전(ap-osaka-1)의 서버에서 처리·보관합니다. 홈페이지나 챗봇 기능 이용 시 필요한 항목을 네트워크로 전송하며, 서비스 제공·저장·복구를 위해 처리합니다. 홈페이지 인증과 일정 요청에는 암호화된 통신을 사용합니다. 각 정보의 보관 기간과 삭제 방법은 위 안내와 같습니다.

서버 제공자: Oracle Corporation. 제공자의 개인정보 처리 및 연락 창구는 Oracle 서비스 개인정보 처리방침에서 확인할 수 있습니다. 홈페이지의 정보 처리·삭제 문의는 아래 운영 연락처로 보내 주세요.

국외 서버 보관을 원하지 않으시면 로그인이나 챗봇 명령을 전송하지 않고 공개 안내를 이용하실 수 있습니다. 가입 후에는 회원 탈퇴 또는 삭제 문의를 통해 정보 보관을 중단할 수 있으며, 이 경우 관련 계정·챗봇 기능은 이용할 수 없습니다.

인공지능 답변: OpenAI

인공지능 기능을 요청하면 4절의 생성 조건과 비교 입력·질문이 OpenAI API에 전송되어 국외에서 처리됩니다. 응답을 나중에 조회하기 위한 저장은 끄고 요청하지만, 공급자의 안전 운영 기록에 입력·응답이 포함될 수 있습니다. 기본 보관은 최대 30일이며, 법적 의무나 위해 방지 등 공급자 정책상 예외가 적용될 수 있습니다.

처리 지역·보관 예외와 문의 경로는 OpenAI API 데이터 처리 안내에서 확인할 수 있습니다. 외부 AI 전송을 원하지 않으면 한마디·메뉴 추천·비교·질문 답변 기능을 사용하지 않을 수 있으며, 게임 정보 조회 등 다른 기능은 이용할 수 있습니다. 개인정보 관련 요청은 아래 운영 문의처로 접수해 주세요.

8. 열람·정정·삭제와 처리정지 요청

개인정보 처리 및 고충 담당: 포근해 길드 운영진 · 문의: maintainer@example.com

내 계정에서 표시 이름과 로그인 서비스를 확인할 수 있습니다. 이름은 해당 서비스에서 수정한 뒤 다시 로그인하면 반영됩니다. 계정에 접근할 수 없거나 개인정보 열람·삭제에 도움이 필요하시면 위 연락처로 문의해 주세요. 비밀번호나 인증 코드를 보내지 마세요.

이용자는 본인의 정보에 대한 정정·삭제, 처리정지와 동의 철회도 요청할 수 있습니다. 챗봇 캐릭터 등록은 등록 해제로 지울 수 있으며, 출석 등 다른 기록의 삭제는 운영진에게 요청해 주세요. 이용한 플랫폼, 해당 계정·닉네임·방과 요청 범위를 알려 주시면 본인 또는 적법한 대리인인지 최소한의 확인을 거쳐 처리합니다. 문의 이메일과 내용은 요청 처리에 사용하고 더 이상 필요하지 않으면 삭제합니다.

법령에 따라 요청이 제한되거나 처리에 시간이 필요한 경우에는 이유와 진행 상황을 안내합니다. 만 14세 미만 아동에 대해 법정대리인의 동의가 필요한 처리는 대리인 확인을 포함한 별도 절차가 필요하며, 보호자는 같은 창구로 열람·삭제를 요청할 수 있습니다.

외부 상담이 필요하면 개인정보침해 신고센터 또는 개인정보 분쟁조정위원회를 이용하실 수 있습니다.

9. 개인정보의 안전한 관리

운영에 필요한 담당자에게만 저장소와 관리 기능의 접근 권한을 부여하고 계정·길드 권한을 확인합니다. 홈페이지 인증에는 세션 보호, 요청 위조 방지와 과도한 요청 제한을 적용합니다. 개인정보 저장 파일과 운영 환경은 공개 홈페이지 파일과 분리합니다. 문제를 확인하면 접근 제한·수정·안내 등 필요한 조치를 합니다.

10. 방침 변경 안내

처리 항목·목적·보관기간이나 외부 서비스가 바뀌면 이 페이지에 변경 사항과 시행일을 알립니다. 중요한 변경은 시행 전에 안내하고, 별도 동의가 필요한 경우에는 해당 절차를 거칩니다. 이전 방침은 운영진에게 요청할 수 있습니다.
